The Tech Stack — What & Why
⚡
FastAPI
Backend Framework · Python
Your Python web server. Handles HTTP requests, WebSocket connections, and routes. It's like Flask but modern — built-in async support means it can handle many real-time connections at once. This is where all your Python logic lives.

pip install fastapi pip install uvicorn
🔌
WebSocket
Real-Time Protocol · Built into FastAPI
The "live pipe" between browser and server. Unlike normal HTTP (ask → wait → reply), WebSocket stays open so the server can push data instantly. Used for: sending transcripts to all users, relaying WebRTC signaling messages, broadcasting who is speaking.

ws://localhost:8000/ws/room-id
📹
WebRTC
Video/Audio Protocol · Browser Native
Browser tech that connects video/audio directly between users (peer-to-peer). Your server just helps them find each other (signaling), then steps aside. Each browser streams directly to the others — no video going through your Python server!

RTCPeerConnection MediaStream API ICE/STUN
🎙️
Whisper
Speech-to-Text · You already use this!
OpenAI's speech recognition model — you already have it from your subtitle project! The difference here: instead of a full file, you feed it short audio chunks (every 3–5 seconds) streamed from the browser via WebSocket, then broadcast the text back live.

openai-whisper numpy + soundfile
🗣️
pyannote.audio
Speaker Diarization · Who Said What
Identifies which speaker is talking. Takes your audio chunk and returns time-stamped speaker labels like "SPEAKER_01 said X". Combined with WebRTC participant IDs, you can label "Alice: ..." vs "Bob: ..." in the transcript.

pip install pyannote.audio HuggingFace token needed
🌏
Translation
Japanese / Korean · Same as your subtitle tool
After Whisper transcribes a chunk, pass it to your translation function. You can reuse your existing code! For real-time use, run translation in a background async task so it doesn't block the transcription pipeline.

deep-translator DeepL API (better quality)
🌐
HTML + Vanilla JS
Frontend · Browser UI
Just HTML, CSS, and plain JavaScript — no frameworks needed! The browser's built-in WebRTC and WebSocket APIs handle the hard parts. You'll learn: DOM manipulation, async/await in JS, event listeners, and media APIs. Great starting point before React.

no framework needed navigator.mediaDevices
💾
SQLite + SQLAlchemy
Database · Transcript Storage
Stores full transcripts after a call ends. SQLite is a single-file database — no server to run. SQLAlchemy is the Python ORM (Object Relational Mapper) that lets you work with the database using Python classes instead of raw SQL.

pip install sqlalchemy no DB server needed

Key Concepts to Understand
🤔 What's the difference between HTTP and WebSocket?
HTTP is like sending a letter: you ask, wait, get a reply, connection closes. WebSocket is like a phone call: stays open, either side can talk anytime. You need WebSocket for live captions.
🤔 What does "signaling" mean in WebRTC?
Before two browsers can video-call, they need to negotiate: "I can do H.264, can you?" and "my IP is X, yours is Y". This negotiation goes through your server (signaling). Once done, video bypasses the server entirely.
🤔 Why use async in FastAPI?
With sync Python, one slow Whisper task would block everyone else. Async lets FastAPI handle 100 WebSocket connections while Whisper runs — it just pauses one task while waiting and handles others.
🤔 What is an ORM?
ORM (Object Relational Mapper) lets you write Python code instead of SQL. Instead of INSERT INTO..., you write db.add(TranscriptLine(...)). SQLAlchemy is the most popular Python ORM.
🤔 How does audio get from browser to Whisper?
JS MediaRecorder captures your mic as binary audio blobs every 3 seconds. These are sent over WebSocket as binary data. FastAPI receives the bytes, saves them as a temp WAV file, then passes the path to Whisper.
🤔 What's a STUN server?
Home routers use NAT — your "real" IP isn't visible to others. A STUN server tells your browser what its public IP looks like from the outside. Google provides free STUN: stun:stun.l.google.com:19302.

main.py — FastAPI skeleton with WebSocket room 
from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.staticfiles import StaticFiles
import json, uuid

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

# In-memory room registry: {room_id: [ws1, ws2, ...]}
rooms: dict[str, list] = {}

@app.post("/room")
async def create_room():
    room_id = str(uuid.uuid4())[:8]
    rooms[room_id] = []
    return {"room_id": room_id}

@app.websocket("/ws/{room_id}")
async def websocket_endpoint(ws: WebSocket, room_id: str):
    await ws.accept()
    rooms.setdefault(room_id, []).append(ws)
    try:
        while True:
            data = await ws.receive_text()   # signaling msgs
            for peer in rooms[room_id]:
                if peer != ws:
                    await peer.send_text(data)
    except WebSocketDisconnect:
        rooms[room_id].remove(ws)
transcribe.py — audio chunk → Whisper → text
import whisper, tempfile, os from concurrent.futures import ThreadPoolExecutor model = whisper.load_model("base") # load once at startup executor = ThreadPoolExecutor(max_workers=2) async def transcribe_chunk(audio_bytes: bytes, loop) -> str: # Save to temp file (Whisper needs a file path) with tempfile.NamedTemporaryFile(suffix=".webm", delete=False) as f: f.write(audio_bytes) tmp_path = f.name # Run Whisper in thread so it doesn't block async def _run(): result = model.transcribe(tmp_path, fp16=False) os.unlink(tmp_path) return result["text"] return await loop.run_in_executor(executor, _run)
